# Security reporting

Bang is pre-1.0 software. Security fixes target the current `main` branch and
latest prerelease; older versions do not receive separate maintenance updates.

Please do not post credentials, tokens, personal messages, or exploit details in
public issues or Discussions. Use GitHub's
[private vulnerability reporting](https://github.com/augustin-laurent/Bang/security/advisories/new)
to contact the maintainer. If reporting is unavailable, ask for a private contact
in an issue without disclosing the vulnerability.

Include the affected commit/version, Linux distribution, reproduction steps with
fictional data, expected behavior, and impact. Do not test against other people's
mailboxes. The maintainer will coordinate a fix and disclosure; no response-time
or bounty commitment is offered.
